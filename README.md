# testeNCURSES-RogueLike

Tecnologias necessárias para compilar este projeto:

```
 Um compilador capaz de compilar código em C(Como GCC ou MVC);

 CMake.
```

Ferramentas para clonar o código:

```
GIT
```

Tendo estas ferramentas:

## Passo 1

Escolha uma pasta onde guardará o projeto e inicialize o CMD neste local.
Feito isso, execute o seguinte comando:

```
git clone <URL_PROJETO>
```

## Passo 2

Após isso, insira o seguinte comando para inicializar a pasta de build e compilar o projeto:

```
cmake -B --build
cmake --build build
```
